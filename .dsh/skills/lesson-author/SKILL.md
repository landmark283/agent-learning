# lesson-author：教学文档生成规范

给学习者（本仓库主人，AI 专业学生，目标：掌握 agent 架构并开发 DSH 插件）生成
任何教学/学习内容时，必须遵守以下三条原则。

## 1. 综合网络上公开的教程

- 优先参考公开教程与官方文档：Anthropic / OpenAI 官方博客与文档、HuggingFace 博客、
  知名开源仓库（Aider、OpenHands、smolagents、teenycode 等）、中文社区高质量文章；
- 同一主题综合 2~3 个来源，取其共识，并在文档末尾写清参考链接；
- 不凭空发明概念名称或过时说法；多个来源冲突时以官方文档为准。

## 2. 结构简洁，逻辑清晰

- 统一骨架：**目标 → 概念/背景 → 动手步骤 → 验收标准 → 参考链接**；
- 一个文档只讲一个主题；多用标题、列表、表格组织，避免长段落堆砌；
- 篇幅克制：能 10 分钟看完的不写 30 分钟的量；代码示例要完整、可直接运行；
- 每个文档标注对应的实践环节（W几-D几，见 `01-学习路径.md`）与理论条目编号
  （见 `02-Agent架构理论清单.md`）。

## 3. 具体举例，确保能听懂

- 每个抽象概念至少配一个具体例子（真实场景或最小可运行代码）；
- 优先举本仓库 / DSH 相关的实例（如"这个机制在 DSH 里对应 `dsh-compaction-basic`"）；
- 叙述顺序固定：先"为什么需要它" → 再"它是什么" → 最后"怎么用"。

## 附加约定

- 练习类文档放在 `try/` 下对应阶段目录（如 `try/01-agent-from-zero/`）；
- 每个练习给出可验收的完成标准（如"测试全绿"、"模型通过工具答出未知答案"）；
- 教学推进后提醒学习者 git commit，保持学习轨迹完整。
