# try/ — 动手练习区

在这里自己写简易 Agent，所有代码都会被提交到 `agent-learning` 仓库。

## 建议的第一个练习：最小 ReAct 循环

1. 选一个支持 Function Calling 的 API（OpenAI / Claude / DeepSeek 均可）；
2. 给模型两个工具：`read_file` 和 `run_command`；
3. 准备一个故意写错的小项目（比如一个函数名拼错、测试不通过）；
4. 让 Agent 自己读文件、跑测试、看报错、修复，直到测试全绿。

预期体验：模型第一次给的修复大概率是错的，但你把报错喂回去它就对了——
这就是"幻觉被工程驯服"的现场。

## 目录约定

每个练习放一个独立子目录，例如：

```
try/
├── README.md
├── 01-mini-react/     # 第一个练习：最小 ReAct 循环
└── ...
```

> 记得随手记录：每个练习写一小段 README，说明设计思路和踩过的坑。
