# notes/ — 一页纸笔记区

记录每个读过的包 / 项目 / 概念的"一页纸"小结。

## 一页纸模板

```markdown
## <包名 / 项目名>

- **解决什么问题**：一句话
- **核心机制**：循环/工具/服务怎么组织的
- **对外暴露**：注册了哪些 service / 工具 / 配置
- **依赖谁**：关键依赖
- **验证点在哪**：它靠什么防幻觉 / 防错误
- **如果重写，我会改**：你的想法
- **疑问**：没看懂的地方（留着问人或日后回来补）
```

## 命名约定

- DSH 包：`dsh-<包名>.md`（如 `dsh-agent-loop.md`）
- 外部项目：`<项目名>.md`（如 `aider.md`）
- 概念：`概念-<名称>.md`（如 `概念-ReAct.md`）
